# 🎞️Star Wars webpage
Esta é uma página web destinada aos amantes do universo de Star Wars, explorando detalhes que geralmente não são vistos em filmes e séries existentes, permitindo que curiosos se integrem à comunidade mais facilmente. 
________________________________________________________________
## 🗒️ Especificações técnicas
- Plataforma: Desktop (em fase de ajustes)
- Linguagem: Html, CSS e Javascript
- Framework: N/E
- Layout: não responsivo
- Design: estilização feita manualmente pelo desenvolvedor
- Arquivos principais: main.html, mainslideshow.js, parallaxmain.css
  | Tecnologia | Funcão |
    | :-------- | :-------: |
    | VSCode | Editor de código Html/CSS/Javascript |
    | Fontspace | Tipografia Personalizada |
    | Html | Linguagem markup base |
    | CSS | Criação de artributos visuais |
    | Javascript | Suporte para animação de slideshow |
## ✏️Aprendizado
Ao desenvolver a página web, aprendi a:
- Utilizar sections além de divs, o que me permitiu otimizar a configuração de diversas divisões de uma página
- Resolver conflitos de sobreposição de objetos
- Integrar novos efeitos visuais para otimização de leitura e inserção de imagens, como parallax
- Organizar documentação essencial para manutenção e futuras modificações do código
## 📒Planejamento futuro
- Trabalhar na responsividade da página, possibilitando o acesso mobile
- Integrar frameworks para otimizar os requisitos de processamento da página
- Reformular os arquivos CSS para melhorar a manutenção a página<br>
